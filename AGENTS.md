# AGENTS.md — Документация проекта «Сокращатель ссылок (URL Shortener)»

## 1. Описание проекта
Учебный курсовой веб-проект для сокращения длинных URL-адресов с поддержкой автоматической генерации коротких кодов и пользовательских псевдонимов.

## 2. Технологический стек и ограничения
- **Язык:** PHP 8.2+ (нативный PHP без фреймворков и без Composer).
- **База данных:** SQLite, подключение через расширение **PDO**.
- **Фронтенд:** Чистые HTML5, CSS3, нативный JavaScript (ES6) без сторонних библиотек.
- **Ограничения архитектуры:** Отсутствуют регистрация, авторизация, личный кабинет, админ-панель и внешние API. Код разделён по ответственности на простые и понятные модули.

## 3. Структура проекта
```text
url-shortener/
├── config/
│   └── db.php          # Подключение к SQLite через PDO
├── assets/
│   ├── style.css       # Стили интерфейса
│   └── script.js       # Копирование короткой ссылки в буфер обмена
├── includes/
│   └── functions.php   # Функции валидации, генерации кода и запросов к БД
├── database.sql        # SQL-скрипт создания таблицы links в SQLite
├── Dockerfile          # Образ приложения на PHP
├── compose.yaml        # Запуск приложения и постоянное хранилище SQLite
├── index.php           # Главная страница: форма ввода, обработка POST-запроса и вывод результата
├── redirect.php        # Поиск короткого кода в БД и HTTP 302 редирект на исходный URL
├── 404.php             # Страница ошибки 404 при отсутствии короткого кода в БД
├── router.php          # Маршрутизатор для запуска через встроенный сервер PHP (php -S)
├── .htaccess           # Правила маршрутизации для веб-сервера Apache
└── AGENTS.md           # Документация проекта и правила для разработки
